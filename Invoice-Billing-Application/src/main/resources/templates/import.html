Excel File Format Guidance:

  • The importer can read any file exported by this application or standard invoice templates.
  • Ensure the sheet contains columns for Description, Quantity, and Unit Price.
  • Customer name, invoice number, and notes can be specified in top header key-value cells.
  • All data is saved completely offline to your local embedded database.
