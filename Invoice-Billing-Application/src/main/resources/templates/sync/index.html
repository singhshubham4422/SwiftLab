Local Only mode keeps your data exclusively on this device. Enabling Cloud Sync will allow selected organization data to be synchronized with the central cloud database.

Multi-device conflicts will be resolved according to the conflict handling rules (inventory movements preserved, master data versioned).

Switch to Local Only Mode

Switching to Local Only mode will immediately halt cloud communication. New sales, purchases, and records created on this device will stay strictly on your local computer.
